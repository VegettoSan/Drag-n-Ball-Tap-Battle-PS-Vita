DRAGON BALL TAP BATTLE - WINDOWS DATA EXTRACTOR

This legacy filename is kept only for compatibility.
For the current English instructions, read README.txt in this folder.

Current public data layout:

  ux0:data/DBTapBattle/profiles/<Profile>/

Every APK is extracted as one independent profile. The profile folder name comes
from the APK filename. The Vita selector shows that folder name.

If you want another name, rename the folder inside:

  ux0:data/DBTapBattle/profiles/

There is no separate game/ and mods/ split in the current layout.

  Extract_APK_for_Vita.bat
