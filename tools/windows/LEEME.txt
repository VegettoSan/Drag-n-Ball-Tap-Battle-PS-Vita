DRAGON BALL TAP BATTLE - WINDOWS DATA EXTRACTOR 1.5 / Vita v1.1

This legacy filename is kept only for compatibility.
For the current English instructions, read README.txt in this folder.

Current public data layout:

  ux0:data/DBTapBattle/profiles/<Profile>/

Every APK is extracted as one independent profile. The profile folder name comes
from the APK filename. The Vita selector shows that folder name.

If you want another name, rename the folder inside:

  ux0:data/DBTapBattle/profiles/

There is no separate game/ and mods/ split in the current layout.

Primary launcher:
  Extract_APK_for_Vita.bat

Legacy-compatible launcher:
  Extraer_APK_para_Vita.bat

VITA v1.1 / UNIVERSAL MOD SUPPORT
- Para los mods PRIVATE nuevos, conserva dbtb_codec.json junto a los PAC.
- Algunas texturas de mods muy pesados pueden verse borrosas porque Vita
  reduce su resolucion para evitar cierres por falta de memoria GPU.
- La extraccion no modifica el APK y los mods no estan garantizados al 100%.
- Guia de instalacion: docs/INSTALLATION_AND_EXTRACTION.md en el repositorio.
