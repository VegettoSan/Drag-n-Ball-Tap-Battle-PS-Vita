DRAGON BALL TAP BATTLE - WINDOWS DATA EXTRACTOR 1.5 / Vita v1.2

This legacy filename is kept only for compatibility.
For the current English instructions, read README.txt in this folder.

Current public data layout:

  ux0:data/DBTapBattle/profiles/<Profile>/

Every APK is extracted as one independent profile. The profile folder name comes
from the APK filename. The Vita selector shows that folder name.

If you want another name, rename the folder inside:

  ux0:data/DBTapBattle/profiles/

There is no separate game/ and mods/ split in the current layout.

Primary launcher:
  Extract_APK_for_Vita.bat

Legacy-compatible launcher:
  Extraer_APK_para_Vita.bat

VITA v1.2 / PS VITA CONTROLS AND RETAINED UNIVERSAL MOD SUPPORT
- Existing profiles do not need re-extraction for v1.2.
- Choose PS VITA CONTROLS or TOUCH ONLY before opening a profile.
- PS VITA CONTROLS hides the touch pads; dialogues remain touch-operated.
- For newly detected PRIVATE mods, keep dbtb_codec.json beside the PAC files.
- Heavy mod textures may be downscaled or appear softer to prevent GPU
  memory exhaustion. Compatibility is not guaranteed for every mod.
- Extraction does not modify the APK or install its save.bin.
- Installation guide: docs/INSTALLATION_AND_EXTRACTION.md in the repository.
